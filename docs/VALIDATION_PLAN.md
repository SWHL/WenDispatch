# WenDispatch 第一阶段验证计划

本文用于回答两个问题：

1. 当前代码是否仍只暴露并处理五个第一阶段平台。
2. 同一篇文章经过 WenDispatch 后，在每个平台的草稿中是否保持可接受的内容和排版。

首期平台固定为 CSDN、稀土掘金、知乎、微信公众号和博客园。真实平台验证一律先保存为草稿，不直接公开发布。

## 验证层次

### 1. 自动化契约

每次提交至少执行：

```bash
pnpm test --run packages/core/src/platforms/__tests__/first-phase.test.ts \
  packages/adapters/src/__tests__/first-phase-registry.test.ts \
  apps/extension/src/__tests__/manifest.test.ts
pnpm --filter @wendispatch/agent-bridge build
pnpm --filter @wendispatch/extension build:fast
pnpm test --run
git diff --check
```

自动化测试应逐步覆盖：

- 平台清单、适配器注册表、Manifest 权限和请求头规则只包含五个平台。
- Markdown 转换保留标题、段落、强调、列表、引用、链接、表格和代码块。
- 知乎和微信公众号 HTML 输出不含危险标签，代码语言、公式替代物和图片顺序可识别。
- 图片清单能识别外链图和粘贴图，上传成功后替换 URL，失败时保留原文并产生明确日志。
- Mermaid、行内公式和块公式按照平台能力输出或明确降级。
- 单平台失败不会阻断其他平台；失败任务可重试，已成功目标不会重复提交。

自动化只证明转换和调度契约，不能证明平台页面结构、登录状态和线上接口仍然有效。

### 2. 扩展冒烟测试

使用 `apps/extension/dist` 加载未打包扩展，在新的 Chrome 测试配置中完成：

1. 打开账号页，只出现五个平台；分别绑定账号并刷新登录状态。
2. 导入或粘贴 `fixtures/platform-validation.md`，确认编辑器和发布前预览均能打开。
3. 选择一个平台创建任务，确认进入正确编辑页且标题、正文已填入。
4. 选择五个平台创建任务，确认任务列表逐平台记录状态、日志和目标 URL。
5. 在一个目标页人为退出登录，确认失败提示包含平台和可执行原因，其他目标继续运行。
6. 恢复登录后执行重试，确认只重跑失败目标。
7. 取消运行中的任务，确认不会继续打开页面或提交内容。

检查 Service Worker 和目标页面控制台，不应出现未捕获异常、旧平台适配器加载或越权域名请求。

单元格只使用以下结果：

- `通过`：与源文语义和顺序一致，无需人工修复。

- `未验证`：本轮没有实际检查。

“证据”填写草稿 URL 或截图路径，并在结果旁附构建 commit。测试草稿标题追加日期和平台名，避免覆盖旧草稿。

## 内容检查表

对每个草稿逐项检查：

- 中文标题、二至四级标题、段落顺序和空行。
- 有序/无序/嵌套列表、任务列表、引用和分隔线。
- 中文标点、粗体、斜体、删除线、行内代码和特殊字符。
- 普通链接的文字与目标地址；图片外层链接不会污染图片地址。
- 代码块语言、缩进、换行、高亮和 HTML 转义。
- 行内公式和块公式；不支持时必须可读地降级，不能静默丢失。
- Mermaid 图表；不支持时保留源码代码块或生成的图，不能变成空白。
- 外链图片、粘贴图片、中文文件名图片的顺序、清晰度和平台内可访问性。
- 草稿状态、成功/失败提示、日志、目标 URL 和重试行为。

## 失败注入

至少验证以下失败场景：

| 场景 | 预期 |
| --- | --- |
| 账号退出登录 | 目标失败并提示重新登录，不误报成功 |
| 图片 URL 返回 404 | 正文仍可读，日志指出图片失败 |
| 图片上传超时 | 按配置重试；最终失败可再次手动重试 |
| 编辑页 DOM 改版 | 报告未找到编辑器或填充失败，不提交空文章 |
| 一个平台失败 | 其余平台继续执行并保留各自结果 |
| 网络中断后恢复 | 失败目标可重试，不重复处理已成功目标 |

## 发布门槛

首个可用版本至少满足：

- 自动化定向测试和两个构建命令通过。
- 五个平台都完成一次真实草稿验证。
- 标题、正文、链接和代码块五个平台均通过。
- 图片、公式和 Mermaid 要么通过，要么有已记录且用户可理解的降级。
- 失败不误报成功，重试不会重复发布已成功目标。
- 每个失败项都有复现步骤、日志和后续 issue。
