# 更新日志

本文件记录 WenDispatch 的版本更新内容。GitHub Release 发布时，将直接使用对应版本的条目作为 Release notes。

## [0.0.8] - 2026-11-25

### 新增

- 发布进行中在任务页与弹窗展示提示，提醒用户不要关闭浏览器或手动操作插件正在使用的标签页。
- 新增注入函数静态检查：基于 AST 发现 MAIN world 中未声明的模块级引用，避免发布时才触发 ReferenceError。

### 修复

- 修复发布完成通知的图标路径错误：从不存在的 `icon.png` 改为 manifest 中声明的 `assets/icon-48.png`。
- 修复发布任务在启动阶段失败时状态未落库的问题：读取任务、写入 RUNNING 或后台执行抛错时均会持久化 FAILED 状态，且不覆盖已完成、失败或已暂停的任务。
- 知乎 HTML 粘贴模式仅提供 text/html，避免编辑器重复解析 text/plain 导致正文出现重复内容。

### 变更

- CSDN 与知乎注入函数的辅助方法改为单一实现，删除仅供测试使用的模块级副本；相关测试改为直接提取并执行注入函数中的真实 helper。
- 跨平台隔离与适配器测试从断言源码字符串改为断言 AST 结构与行为输出，同时保留知乎关键粘贴回归断言。

### 测试

- 新增任务失败状态落库、通知图标路径、注入函数自由标识符与跨平台隔离等回归测试。

## [0.0.7] - 2026-10-12

### 新增

- 新增发布前检查（Preflight）能力：按平台和账号独立检查标题、正文、图片、标签、分类、封面、公式及 Mermaid 等内容差异。
- 发布前展示平台最终转换产物、图片处理方式、阻止项、警告项和人工确认步骤；存在阻止项时禁止创建发布任务，警告项需确认后继续。
- 将发布前检查结果、内容指纹和警告确认状态保存到发布任务，便于后续诊断和审计。
- 新增 Markdown 常用片段库，支持预置片段插入、基于预置新建，以及自定义片段的保存、编辑和删除。
- 新增文章复制功能，复制后的文章拥有独立 ID、版本和时间信息，不会复制原文章的发布任务映射。
- 为编辑、复制、删除、登录、重新登录、关闭和外部链接等操作补充图标，提高操作辨识度。

### 变更

- 发布流程调整为“先检查发布内容，再确认并创建发布任务”。
- 发布前检查复用各平台适配器的实际转换结果，确保预览内容与后续填充内容一致。

### 测试

- 新增平台发布前检查测试，覆盖转换产物、缺失标题或图片阻止、多平台结果独立性等场景。
